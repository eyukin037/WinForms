Приложение Windows Forms.
Использование нескольких форм (главная форма + диалоговые/дополнительные).
Главное меню (MenuStrip) с пунктами: Файл, Данные, Отчёт, Справка.

ОБЯЗАТЕЛЬНЫЕ
Элементы управления:
Списки (ListBox, ComboBox, ListView или DataGridView).
Прокрутка (ScrollBar или TrackBar) – для настройки параметров.
Индикаторы (ProgressBar) – для длительных операций.
Обработка исключений (ввод данных, файловые операции, расчёты).
Работа с файловой системой:
OpenFileDialog / SaveFileDialog (загрузка/сохранение данных).
Логирование действий в текстовый файл.
Сериализация/десериализация (JSON или XML) для хранения данных.
События и делегаты (реакция на действия пользователя, уведомления).
Код должен быть структурирован (папки: Models, Forms, Services, Helpers)


Калькулятор матриц с обработкой ошибок
Описание: Приложение для операций с матрицами (+/-/det/обратная).
Ввод матриц произвольного размера (динамическое добавление полей).
Проверка на возможность операции (например, умножение только MxN на NxK).
Подробные ошибки ("Нельзя найти обратную матрицу: det=0").
